# Toys

Small self-contained browser toys, each a single static HTML file (no build step, no dependencies).

Live: https://omniaetnihil.github.io/toys/

| Toy | File | What it is |
|---|---|---|
| NEON-16 drum machine | [drum-machine.html](drum-machine.html) | 11-track step sequencer, bass synth, song mode, mix & FX, live record, WAV/MIDI export |
| Flow field | [flow-field.html](flow-field.html) | Generative particles in a noise field |
| Gravity sandbox | [gravity.html](gravity.html) | Fling planets, grow stars, n-body merging |

Run locally: open any file in a browser, or `python3 -m http.server` in this folder.

Deployed to GitHub Pages by `.github/workflows/pages.yml` on every push to `main`.
